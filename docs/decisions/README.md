# Architecture Decision Records

Architecture Decision Records (ADRs) registram decisões arquiteturais importantes quando sua justificativa e consequências precisam ser preservadas historicamente. Não substituem [SPECIFICATION.md](../../SPECIFICATION.md), que continua sendo a fonte de verdade dos requisitos da V1.

Um ADR deve ser criado quando uma decisão nova ou uma mudança relevante merecer contexto durável. Use numeração sequencial e mantenha documentos substituídos em vez de apagá-los.

## Template

```markdown
# ADR-XXXX — Título

## Status

Proposto | Aceito | Substituído

## Contexto

Descreva o problema.

## Decisão

Descreva a decisão.

## Consequências

Descreva vantagens, limitações e impactos.
```
